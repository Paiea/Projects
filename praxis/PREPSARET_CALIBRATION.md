# Private 5003 Calibration Map

Basis: user-provided `math prepsaret.docx` (115 pages). The document contains 15 `PLAY QUIZZES AUDIO` study sections. The DOCX package contains document XML only and no embedded media or separate quiz payload, so the saved file exposes the study/explanation layer rather than an extractable interactive quiz bank.

This map is used to calibrate ORIGINAL generated items. It is not copied into the public app as proprietary quiz content.

1. Place value: numeral/name/expanded form; compose/decompose; digit value; powers of 10; exponents; rounding.
2. Rational operations: operation situations; inverse relationships; remainder interpretation; rational algorithms; magnitude; fraction composition/decomposition; representations/conversions.
3. Number theory: prime/composite; factors; multiples.
4. Proportional relationships and percents: ratios; unit rates; percent per 100; proportions; percent problems.
5. Reasonableness: contextual reasonableness; mental math; front-end/compatible/range estimation; rounding.
6. Expressions/equations/formulas: expression vs equation; combine terms; distributive property; evaluate; terminology; verbal translation; formulas; variable roles.
7. Linear equations/inequalities: multistep solving; interpretation; equations/tables/graphs.
8. Patterns: identify/extend/generate; conjecture/generalize; corresponding numerical patterns/function tables.
9. Figure classification: lines/rays/segments; parallel/perpendicular; angle classification; compose/decompose shapes; polygon/solid attributes.
10. Perimeter/area/surface area/volume: nets; surface area from nets; polygon area/perimeter; prism volume/surface area; dimension changes.
11. Coordinate plane: axes/origin/quadrants; plot points; polygons and coordinate problems.
12. Measurement: elapsed time; money; length; volume; mass; measurement tools; customary/metric relative sizes and conversions.
13. Statistics: statistical questions; mean/median/mode/range; best center; effect of data changes; patterns/outliers.
14. Data displays: interpret displays; construct/complete graphs; choose appropriate display.
15. Probability: interpret probability relative to likelihood.
