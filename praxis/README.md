# Praxis 5001 Study Engine

Durable home for Keoni's Praxis Elementary Education: Multiple Subjects study system.

## Scope
- 5002 Reading & Language Arts
- 5003 Mathematics
- 5004 Social Studies
- 5005 Science

## Study model
Performance training rather than passive review:
1. Diagnostic questions
2. Track knowledge, speed, and confidence under pressure
3. Classify errors
4. Target weak skills
5. Re-test under time pressure
6. Periodically run mixed/timed simulations

## Error types
- Concept gap
- Procedure error
- Misread question
- Time-pressure / second-guessing

## Web app goal
A lightweight GitHub Pages study app that supports:
- subject/subtest selection
- one-question-at-a-time practice
- answer explanations
- local progress tracking
- weakness/error ledger
- targeted weak-area practice
- mixed Praxis mode

## Authority
This folder is the durable Praxis authority. Recover useful prior Praxis material from ChatGPT Library/project artifacts into this project rather than rebuilding it from memory.
