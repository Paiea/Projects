# Reference Packet Specification

This is a sanitized reconstruction of a successful Grade 2 full-day packet architecture developed through repeated classroom-use QA. It is a **reference**, not a frozen curriculum and not a student record.

## Why keep this reference

The useful part is not the exact questions. It is the structure that survived iteration:

- a visible learning map
- permission to work ahead without demanding teacher help
- substantial academic work
- real quiet coloring resets
- one open create/design page
- separated math questions
- enough writing space
- optional harder challenge work
- teacher/sub artifacts matched to final page numbers
- explicit end-of-day finish time

## Reference 12-page packet

### Page 1: Today + How This Packet Works + Warm-Up

Top of page:

**TODAY WE ARE LEARNING TO...**

- solve math stories and show our thinking
- use the week's spelling pattern
- find what happens in a sentence
- write one clear idea with details
- think about friendship/helping/current read-aloud idea
- work independently and return to skipped problems

Then:

**HOW THIS PACKET WORKS**

- class will use most pages throughout the day
- students may go ahead
- mark `?` if truly stuck
- keep moving
- return when class reaches the page
- finish MOST by end of day
- careful work beats racing

Bottom: short warm-up, not a second full worksheet.

### Page 2: Math, One Problem at a Time

- 5–6 facts within the current range
- 2–3 missing-number equations
- one story problem
- equation + answer space
- one check / second representation

Formatting: one numbered computation per line. Do not make a horizontal wall of math.

### Page 3: True Coloring Reset

Theme can connect to perseverance / independence.

No required writing. The point is a genuine quiet reset.

### Page 4: Spelling / Phonics Pattern

Example architecture:

- word bank
- sort by pattern
- table capacity checked against exact item count
- 2–3 complete sentences using words
- one small word-detective question

If a word can plausibly fit multiple categories, rewrite the task.

### Page 5: Grammar

Example progression:

1. identify target skill
2. fix one sentence
3. finish/build one sentence
4. expand a sentence
5. independently create one

This uses the page better than ten nearly identical identification items.

### Page 6: Writing

One substantial Grade 2 prompt connected to the day.

Give enough lines. Do not split the prompt from its writing space across pages.

### Page 7: True Coloring Reset

Theme can connect to friendship, belonging, reading, nature, teamwork, etc.

Again: coloring, not another drawing assignment.

### Page 8: Read + Think

Short response to read-aloud / current story.

Possible response modes:

- words
- picture + words
- one evidence/detail question
- one lesson/idea question

Avoid reproducing copyrighted story text.

### Page 9: Math Thinking

Use 2–3 distinct problem structures rather than three cosmetic variants of the same problem.

For example:

- part unknown
- change unknown
- compare

Then one short explanation prompt.

### Page 10: Create Mode

Pick ONE, not all.

Examples:

- math fortune-teller plan
- secret spelling decoder
- mini invention

Use a large workspace intentionally. Require just enough structure that another second grader could understand the creation.

### Page 11: Checkpoint / Mixed Review

A compact independent check across the day's main targets.

Do not simply repeat exact questions from earlier pages. Same skill, fresh item.

### Page 12: Open Drawing / Design

Keep one genuinely open page after replacing other fake-break drawing prompts with real coloring pages.

Example: classroom inventor, comic, design-a-tool, or another application task.

## Reference challenge set

Keep challenges separate from the main packet.

### Math Detective

- multi-representation reasoning
- missing part
- odd/even explanation
- related equations
- create a tricky but valid Grade 2 problem with one clear answer

### Word + Writing Lab

- use current spelling pattern in context
- grammar target in authentic sentences
- revise weak sentences
- short extended writing

### Design Lab

- identify a problem
- labeled solution
- materials/resources
- test
- improve
- explain / advertise

## Reference teacher artifact set

For a sub day, pair the student packet with:

- 2-page substitute guide
- one-page exact packet map
- quick answers + reset menu
- 2–4 copies of each challenge packet
- optional daily slides

## Known failure modes caught during iteration

These are worth preserving because they recur in generated worksheets:

1. **Table capacity mismatch:** ten sort words but too few answer lines.
2. **Wrong category key:** a word accidentally assigned to the wrong blend/category.
3. **Ambiguous compare wording:** “6 fewer” without saying fewer than whom.
4. **Dense math strings:** many equations on one line, visually hard for Grade 2.
5. **Verbatim recycling:** same facts/prompts surviving from previous packets without an instructional reason.
6. **Artifact drift:** sub notes referring to old page numbers after the packet changed.
7. **Fake reset pages:** asking students to invent/draw every time when what the day needs is actual low-demand coloring.
8. **Accidental whitespace:** academic pages with giant unused lower thirds.
9. **Overfilling intentional workspace:** trying to eliminate blank space from drawing/coloring/design pages.
10. **No daily story:** students can complete pages but cannot tell what they are learning today.

The QA gate in `PACKET_ENGINE.md` exists specifically to catch these.
