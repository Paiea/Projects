# PROJECT BRAIN STARTER

Copy the files in this folder into a new internally hosted project, then replace the bracketed guidance with real project state.

Start small. Most projects need only:

- a human-facing `README.md` or `index.html`
- `PROJECT_STATE.md`
- project-local `AGENTS.md` only when the root repository router is not enough

Read [`../../docs/PROJECT_BRAIN_STANDARD.md`](../../docs/PROJECT_BRAIN_STANDARD.md) before adding specialist state files.

## Setup checklist

1. Create the project source folder.
2. Add or copy `PROJECT_STATE.md` and fill in exact authority paths.
3. Add a project-local `AGENTS.md` only if the project needs special routing.
4. Register the project in `../../state/PROJECT_REGISTRY.md`.
5. Add a public hub card only if the project is intentionally public.
6. End the initial state with a real `NEXT_TASK` or `HOLD / OBSERVE` and a compact GitHub-directed `RE-PROMPT`.
